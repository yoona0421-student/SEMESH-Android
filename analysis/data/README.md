# 데이터 출처와 설명

`raw/` 폴더의 파일은 **내려받은 그대로** 두고 수정하지 않습니다.
전처리 결과는 `processed/`에 따로 저장합니다. 원본이 남아 있어야 분석 과정을 다시 돌려볼 수 있기 때문입니다.

모든 데이터: 주택도시보증공사(HUG) 제공, 공공데이터포털(data.go.kr), 이용허락범위 제한 없음, 2026-11-05 내려받음

## 1. 지역별 전세금반환보증 사고현황 (2026.8 기준) ← 이번 분석의 핵심 최신 데이터

- 파일: `HUG_지역별_전세금반환보증_사고현황_20260831.xlsx`
- 출처: https://www.data.go.kr/data/15134221/fileData.do
- 범위: 전국 시/도/시군구 (기초지자체 261개 + 소계 행), **최근 3개월(2026.6~8) 평균**
- 컬럼: 법정동코드(5자리) · 광역지자체 · 기초지자체 · 사고건수(건) · 사고금액(원) · 사고율(%)
- 구조 주의점
  - 위쪽 5줄은 제목·병합된 머리글이라 읽을 때 건너뛰어야 함
  - `소계` 행(전국·수도권·지방·시도 합계)이 시군구 행과 섞여 있음 → 시군구 분석 시 제외
  - **사고 1건만으로 사고율이 100%가 되는 지역이 있음**(예: 전남 장흥군). 표본이 작은 지역의 사고율은 그대로 믿으면 안 됨 → 분석 단계에서 처리 방법을 정해야 함

## 2. 서울 행정동별 경공매지원 피해주택 소재건수 (2023.7 ~ 2026.10)

- 파일: `HUG_서울_행정동별_경공매지원_피해주택_20261029.csv` (UTF-8 BOM)
- 출처: https://www.data.go.kr/data/15178286/fileData.do
- 범위: 서울 25개 자치구 중 24개 구, 219개 행정동, 월별, 1,263행
- 컬럼: 연 · 월 · 시군구 · 읍면동 · 경공매지원건수
- 누적 상위: 강서구 448 · 금천구 220 · 구로구 178 · 관악구 168 (지난 학기 결과와 같은 경향)

## 3. 경공매지원서비스 신청자의 전세사기피해주택 소재지(시군구) (2023.7 ~ 2025.3)

- 파일: `HUG_경공매지원_피해주택_소재지_시군구_20251231.xlsx` (지난 학기에 쓴 파일과 동일, 포털 최신본과도 동일)
- 출처: https://www.data.go.kr/data/15139145/fileData.do
- 범위: 전국 시군구, 시트 3개(2023년 7월~, 2024년, 2025년 ~3월)
- 컬럼: 시군구 · 피해주택수

## 데이터 한계 (논문 '한계점'에 반드시 쓸 것)

- 2·3번은 **전체 전세사기 피해자가 아니라 HUG 경공매 지원을 신청한 피해자**의 주택만 포함
- 1번은 **HUG 전세보증에 가입한 계약**의 사고만 포함 (보증 미가입 계약은 빠짐)
- 1번은 최근 3개월만의 값이라 계절·일시적 변동이 섞여 있을 수 있음
